# Pravila projekta i evidencija izmjena

## Obavezno pravilo za verzije (CHANGELOG)
Nakon svakog uspješno završenog zadatka, ispravka greške ili implementacije nove funkcionalnosti:
1. Obavezno ažuriraj datoteku `CHANGELOG.md` u korijenu projekta.
2. Ako se radilo o većem paketu izmjena, uvećaj verziju (npr. `## [v2.2] - YYYY-MM-DD`).
3. Zapiši promjene pod točnim sekcijama:
   - **Dodano (Added):** nove značajke, ekrani, API rute
   - **Ispravljeno (Fixed):** otklonjeni bugovi
   - **Baza / Migracije:** dodane EF Core migracije
   - **Otvorene odluke (Open Decisions):** pravila koja čekaju poslovnu potvrdu
4. U svom završnom odgovoru uvijek ispiši kratki sažetak onoga što si unio u `CHANGELOG.md`.
